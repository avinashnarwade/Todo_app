📝 To-Do App (Django)

A To-Do web application built with Django that helps users efficiently organize, track, and manage their daily tasks. This project focuses on simplicity, usability, and clean backend architecture while demonstrating core Django concepts and best practices.

The application allows users to create, update, mark as complete, and delete tasks, ensuring better productivity and task management. All data is handled securely using Django’s ORM and follows the MVC (Model–View–Template) design pattern.

This project is ideal for showcasing Django fundamentals, backend development skills, and CRUD functionality in a real-world web application.

✨ Features

Create, edit, and delete tasks

Mark tasks as completed or pending

User-friendly interface

Django ORM for database management

Clean and maintainable project structure

🛠️ Tech Stack

Backend: Django (Python)

Frontend: HTML, CSS, Bootstrap (optional)

Database: SQLite (default)

🚀 Purpose of the Project

This project was built to practice and demonstrate:

Django models, views, and templates

CRUD operations

Web application workflow using Django

Backend development fundamentals
